# user-segmentation-engine

RFM + K-Means сегментация пользователей.

## Возможности
- RFM-скоринг (R, F, M по 5-балльной шкале)
- Классификация на 8 сегментов (Champions, Loyal, At Risk и т.д.)
- K-Means кластеризация
- ABC-анализ по revenue
- Streamlit-дашборд

## Быстрый старт
cp .env.example .env
docker-compose up --build
